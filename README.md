# 桌宠（Desktop Pet）

一个使用 **Python + PyQt5** 编写的 Windows 桌面宠物（天选姬风格）：GIF 动画、语音对话、系统声音识别、音乐播放器、散步模式、气泡装饰与彩蛋一应俱全。

---

## 功能特性

**窗口与外观**

- 无边框 / 透明背景 / 窗口置顶，默认 200×200，启动位于屏幕右下角
- 十种状态对应十张 GIF 动画，默认「坐坐」；待机每隔一段时间随机切换状态（间隔可在主菜单调整）
- 全局等比缩放：人物、气泡、文字、装饰图片、控制面板随「桌宠大小」同步缩放（50%–200%）
- 对话气泡：橙色圆角背景 + 三角指示器，按文字长度自动折行与调整大小
- 气泡装饰（随机两种样式）：
  - 样式一：`ui/1.png` 放右上角、`ui/2.png` 放左上角
  - 样式二：`ui/3-7.png` 半透明贴纸，随机且互不重叠地分布在气泡内
- 气泡显示在人物上方；空间不足时自动翻转到下方，不会遮挡人物

**交互**

- 左键拖拽移动窗口；左键单击弹出对话气泡（气泡会平滑跟随人物移动）
- 右键菜单：我想听歌 / 开始放歌！/ 状态选择 / 散步模式 / 音频电平条 / 主菜单
- 主菜单：置顶开关、桌宠大小滑动条、状态切换间隔、音频电平条开关、音乐软件路径、歌曲文件夹、重启桌宠、显示/隐藏、退出
- 系统托盘：单击显示、右键菜单支持显示/隐藏与退出；关闭窗口时最小化到托盘
- 开机自启开关（写入当前用户注册表 Run 项，无需管理员权限）
- 彩蛋：0.5 秒内连续左键点击 10 次 → 全屏显示 `easter_egg.jpg`，7 秒后自动消失（点击或 ESC 可提前关闭）

**散步模式**

- 上下左右四个方向等概率随机移动，每个方向持续 30–60 秒后自动换向
- 碰到屏幕边缘自动反弹
- 移动动作使用「送货 / 纸飞机 / 骑行」，左右移动时会按朝向水平镜像；上下移动使用「潜水」
- 关闭散步模式后自动恢复进入前的状态

**声音识别与音频电平条**

- 人物左侧显示五条音频电平条，实时反映系统声音大小（可在主菜单或右键菜单关闭）
- 听到**外部系统声音**持续 3 秒后自动切换到「看书」状态，静音 2 秒后恢复
- 点击桌宠自己播放的语音不会触发状态切换

**音乐播放**

- 「开始放歌！」：从歌曲文件夹随机播放，弹出右侧控制面板
  - 控制面板：上一首 / 播放暂停 / 下一首（图形按钮）+ 进度条（可拖动跳转）+ 当前歌名
  - 切歌随机、歌名气泡提示、播完自动随机下一首
  - 播放失败（文件损坏等）自动跳过，不会卡死
  - 采用 Windows MCI 播放引擎（不依赖 Qt 多媒体），wav / mp3 均可播放
- 「我想听歌」：启动本地音乐软件（自动检测网易云 / QQ音乐 / 酷狗 / 酷我，或手动指定路径，也可打开网页版网易云）

**其他**

- 设置持久化：退出后不丢失，重启自动恢复（桌宠大小、切换间隔、电平条开关、置顶状态、软件路径、歌曲文件夹）
- 配置与代码分离：文字、语音、歌曲、装饰图片全部读文件夹，替换素材无需改代码

## 环境要求

- Windows 10 / 11
- Python 3.8 及以上（推荐 3.12）
- 依赖库：PyQt5、numpy、soundcard

## 安装与运行

```bash
pip install -r requirements.txt
python desktop_pet.py
```

首次运行会自动创建缺失的资源文件夹（`gifs`、`texts`、`audio`、`ui`、`语音包和文字`、`夏日活动主题曲`）。

## 目录结构

```
desktop-pet/
├─ desktop_pet.py           主程序（单文件，包含全部逻辑）
├─ requirements.txt         依赖清单
├─ README.md
├─ easter_egg.jpg           彩蛋图片（0.5 秒内连点 10 次触发）
├─ gifs/                    十张状态动画 GIF
│   ├─ 购物.gif  海边.gif  看书.gif  拍照.gif  骑行.gif
│   ├─ 潜水.gif  送货.gif  探险.gif  纸飞机.gif  坐坐.gif
├─ texts/                   对话气泡文字（.txt，随机取一条）
├─ audio/                   点击气泡时的随机音效（可为空）
├─ ui/                      气泡装饰图片（1-2 角标、3-7 随机贴纸）
├─ 语音包和文字/             同名 .txt + .wav 配对（点击桌宠时文字与语音同时输出）
└─ 夏日活动主题曲/           歌曲文件夹（放 mp3/wav，「开始放歌！」随机播放）
```

> 说明：为避免仓库体积过大，仓库**未包含歌曲文件**（wav 体积是 mp3 的 8–10 倍），请自行把喜欢的音乐放进 `夏日活动主题曲/` 文件夹。

## 资源自定义

| 文件夹 | 放什么 | 说明 |
| --- | --- | --- |
| `gifs/` | 十张 GIF | 文件名固定：`购物.gif`、`海边.gif`、`看书.gif`、`拍照.gif`、`骑行.gif`、`潜水.gif`、`送货.gif`、`探险.gif`、`纸飞机.gif`、`坐坐.gif`；缺失时显示文字占位不会崩溃 |
| `texts/` | `.txt` | 左键点击时随机取一条内容显示；为空时显示默认文字「请输入文本」 |
| `语音包和文字/` | 同名 `.txt` + `.wav` | 例如 `任命助理.txt` + `任命助理.wav`，点击桌宠时两者同时输出，支持 UTF-8 / GBK 编码 |
| `audio/` | 任意音频 | 未配置语音包时，点击气泡会随机播放这里的音频 |
| `ui/` | `1.png` ~ `7.png` | 气泡装饰图，样式一使用 1、2 号，样式二使用 3–7 号 |
| `夏日活动主题曲/` | `.mp3` / `.wav` | 「开始放歌！」的随机歌单，可在主菜单改为其他文件夹 |
| 程序目录 | 任意 `.jpg` | 作为彩蛋图片（默认读取 `easter_egg.jpg`） |

## 配置文件

程序会在 exe / 脚本同目录自动生成两个配置文件（JSON 格式，可手动编辑）：

**settings.json**

```json
{
  "pet_scale": 1.0,
  "idle_interval_ms": 600000,
  "meter_enabled": true,
  "topmost": true
}
```

- `pet_scale`：桌宠大小倍率（0.5–2.0）
- `idle_interval_ms`：待机状态切换间隔（毫秒，1 分钟–24 小时）
- `meter_enabled`：是否显示音频电平条
- `topmost`：是否窗口置顶

**music_config.json**

```json
{
  "music_path": "D:\\CloudMusic\\cloudmusic.exe",
  "songs_dir": "D:\\Music\\我的歌单"
}
```

- `music_path`：「我想听歌」启动的本地音乐软件
- `songs_dir`：自定义歌曲文件夹（默认 `夏日活动主题曲`）

删除配置文件即可恢复默认设置。

## 打包成 exe

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name 桌宠 desktop_pet.py
```

打包完成后，把 `gifs`、`texts`、`audio`、`ui`、`语音包和文字`、`夏日活动主题曲` 复制到 exe 同目录即可分发（程序会以 exe 所在目录作为资源根目录）。

## 常见问题

**1. 音频电平条不动？**
确认已安装 `soundcard`（`pip install soundcard`），且系统正在播放声音；程序目录下的 `audio_debug.log` 会记录采集状态，便于排查。若系统不支持回环采集，电平条会保持静止但不影响其他功能。

**2. 点击「开始放歌！」没声音？**
确认 `夏日活动主题曲/` 文件夹里有 mp3 或 wav；个别损坏文件会被自动跳过。

**3. 点击桌宠没有语音？**
语音需要 `语音包和文字/` 中成对存在的 `.txt` 与同名 `.wav`。

**4. 左键拖不动 / 点不到？**
可能有旧实例在运行，请先在任务管理器结束旧的「桌宠」进程。

**5. GIF 不显示？**
检查 `gifs/` 中文件名是否与上表一致；文件缺失时会显示橙色文字占位提示。

## 技术实现

| 功能 | 实现方式 |
| --- | --- |
| 界面框架 | PyQt5（Qt 5.15） |
| GIF 播放 | QMovie 逐帧取图 + 自绘（支持水平镜像与等比缩放） |
| 气泡绘制 | QPainter 自绘圆角矩形 + 三角指示器，按字符宽度折行 |
| 系统音频采集 | `soundcard`（WASAPI 回环麦克风） |
| 音乐播放 | Windows MCI（`mciSendString`，waveaudio / mpegvideo） |
| 语音播放 | QMediaPlayer，wav 兜底 winsound |
| 系统集成 | QSystemTrayIcon（托盘）、winreg（开机自启） |
| 打包 | PyInstaller（单文件模式） |
